TWITCH IPTV - RAILWAY + AD-FREE
=================================

Questa versione include:
- UI Twitch IPTV
- M3U + EPG
- LIVE Twitch
- REPLAY automatico con ultima VOD
- proxy anti-ad con più fallback
- Streamlink come ultimo paracadute (filtra gli spot; può fermarsi durante il break)
- compatibilità Railway

CARICAMENTO:
1. Su GitHub apri il repository già collegato a Railway.
2. Sostituisci server.py, requirements.txt, railway.json, streams.txt.
3. Commit changes.
4. Railway farà il redeploy automaticamente.
